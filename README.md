# Rei Lear · 9º ano C

Ficha auxiliar de leitura de *Rei Lear*, tragédia de William Shakespeare na adaptação em prosa de Hildegard Feist (Scipione, série Reencontro).

Inclui a trama, os personagens, a análise para prova, vocabulário, lacunas e questões com correção.

```bash
npm install
npm run dev
```

O app sobe em `http://127.0.0.1:8080`.
